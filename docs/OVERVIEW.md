# Обновление header сайта-лэндинга

Для обновления header сайта-лэндинга необходимо внести изменения в файл MenuHeader.astro, который находится в папке src/components/Header. План действий: 1. Создать новую ветку для работы над фичей. 2. Открыть файл MenuHeader.astro и заменить текст кнопок в меню на английский язык. 3. Протестировать изменения локально, чтобы убедиться, что все кнопки отображаются корректно. 4. Создать pull request для слияния изменений в основную ветку, который должен быть подтвержден вручную.
