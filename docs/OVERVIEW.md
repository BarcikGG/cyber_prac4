# Обновление header в проекте

Для обновления заголовка (header) в проекте необходимо внести изменения в файл MenuHeader.astro, который находится в папке src/components/Header. План действий: 1. Открыть файл MenuHeader.astro. 2. Найти все текстовые элементы, которые необходимо перевести на английский язык. 3. Заменить текст на английский. 4. Проверить, чтобы изменения не нарушили структуру и стили компонента. 5. Создать новую ветку для этих изменений. 6. После завершения работы, сделать pull request и дождаться ручного подтверждения перед пушем в main.
